# Quy định nghiệp vụ - Phân loại Nhà cung cấp & Vật tư

Dưới đây là bảng định nghĩa mã loại nhà cung cấp và phạm vi quản lý vật tư tương ứng trong hệ thống:

| Code      | Phạm vi nên quản lý                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------ |
| PAPER     | Giấy tờ, giấy cuộn                                                                                     |
| MATERIAL  | Các vật tư không thuộc các nhóm chuyên biệt (màng PET, Metalized, PVC, foam, vải, carton, lõi giấy...) |
| INK       | Mực in                                                                                                 |
| GLUE      | Keo, băng keo                                                                                          |
| SOLVENT   | Dung môi, IPA, xăng, cồn, hóa chemical pha mực nếu không tách riêng                                    |
| PLATE     | Kẽm in                                                                                                 |
| DIE       | Khuôn bế, khuôn nổi, khuôn ép kim...                                                                   |
| ACCESSORY | Vật tư tiêu hao, phụ kiện, bao bì đóng gói, dao gạt, lõi giấy, găng tay...                             |
| PRINTING  | Nhà gia công in, gia công ngoài                                                                        |
